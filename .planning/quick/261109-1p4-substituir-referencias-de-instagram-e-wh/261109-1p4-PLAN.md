# Quick Plan: Substituir referências de Instagram e WhatsApp pelos arquivos SVG

## Objective
Substituir todas as referências visuais/ícones de WhatsApp e Instagram no `index.html` pelas imagens SVG dedicadas presentes em `imagem/`:
- `imagem/WhatsApp.svg`
- `imagem/instagram-2-1-logo-svgrepo-com.svg`

## Scope
1. **Top Bar**:
   - Link de WhatsApp: Adicionar `<img src="imagem/WhatsApp.svg" alt="WhatsApp" width="18" height="18" class="top-bar__icon">` antes do número.
   - Link de Instagram: Trocar o SVG inline genérico por `<img src="imagem/instagram-2-1-logo-svgrepo-com.svg" alt="Instagram" width="18" height="18" class="top-bar__icon">`.

2. **Cards de Produtos (7 botões)**:
   - Substituir o emoji `💬` no botão "Pedir pelo WhatsApp" por `<img src="imagem/WhatsApp.svg" alt="" width="20" height="20" class="btn__icon">`.

3. **Seção Contato**:
   - Card WhatsApp: Trocar emoji `💬` por `<img src="imagem/WhatsApp.svg" alt="WhatsApp" width="32" height="32">`.
   - Card Instagram: Trocar emoji `📸` por `<img src="imagem/instagram-2-1-logo-svgrepo-com.svg" alt="Instagram" width="32" height="32">`.

4. **Rodapé (Footer)**:
   - Links sociais do rodapé: Adicionar os ícones SVG ao lado dos textos "WhatsApp" e "Instagram".

5. **Botão Flutuante (FAB)**:
   - Trocar o SVG monocromático inline pelo `<img src="imagem/WhatsApp.svg" alt="WhatsApp" width="36" height="36" class="btn--fab__img">`.

6. **Estilos CSS (`css/components.css`)**:
   - Ajustar classes auxiliares (`.top-bar__icon`, `.btn__icon`, `.btn--fab__img`, `.contact-card__icon img`) para perfeito alinhamento vertical e proporção.
